This is a placeholder, not a post. It gives the first real post something to copy, and it shows every element the writing pages support so they can be checked in both themes. It stays on the dev server. Production builds, Vercel previews included, leave it out of the index, the feed and the sitemap, and its URL returns a 404.

## Publishing a post

1. Copy this file in `content/writing/` and rename it. The file name becomes the URL.
2. Fill in the frontmatter at the top.
3. Delete the `draft: true` line when it is ready to go out.

```yaml
---
title: "The post title"
date: 2026-10-30
description: "One or two sentences. Shown on the index, in the feed and on share cards."
---
```

| Field         | Required | Notes                                         |
| ------------- | -------- | --------------------------------------------- |
| `title`       | Yes      | Plain text.                                   |
| `date`        | Yes      | `YYYY-MM-DD`. Sets the order on the index.    |
| `description` | Yes      | Used wherever the post is summarized.         |
| `draft`       | No       | `true` keeps the post on the dev server only. |

The build fails and names the file if a required field is missing, so a broken post can't go out by accident.

## Code

Fence a block and name the language. Long lines scroll inside the block, so the page itself never scrolls sideways on a phone.

```ts
export function getPosts(): Post[] {
  return readdirSync(POSTS_DIR)
    .filter((file) => file.endsWith(".mdx"))
    .map(readPost)
    .filter((post) => SHOW_DRAFTS || !post.draft)
    .sort((a, b) => b.date.localeCompare(a.date));
}
```

```bash
# Check what production will show. Drafts are gone from this build.
npm run build && npm run start -- --port 3077
```
